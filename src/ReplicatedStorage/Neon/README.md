## 已经钉住的设计决定（12 条）

1. **记录是调用时刻的快照，且冻结**。输出端拿到同一个引用（省内存、可断言），代价是「先打印后改表」不会影响日志。
2. **未登记的级别当场抛错**，不降级成 `info`；`"INFO"` 这类大小写差异可以接受。被猜出来的级别会伪装成一条正常记录。
3. **级别过滤不属于输出端**（那是 `P2.W4` 的过滤器）。`Sink.Write` 只有 `name` 与 `Write` 两个字段：接缝每多一个必选方法，第三方输出端就多一处会漏实现的地方。
4. **渲染只依赖记录本身**：不读时钟（时间取 `record.time`）、不印地址（函数/userdata 只给类型）、表按键排序。这样「同一条记录渲染两次必须逐字节相同」才成立 —— 这条判据是 `P2.W3` 的核心，一旦引入地址或本地时区就永久失败。
5. **截断必须标出来**。省略号计入上限，被丢掉的字节数写在正文尾部 `(+N)`；只留省略号等于把人朝「看到的就是全文」的方向打发。`(+N)` 允许让整行比上限多几个字节：为了凑整数上限而丢掉「少掉多少」这个信息不划算。`(+N)` 数的是**渲染后**的字节，因为上限管的是输出宽度，而转义会放大正文。
6. **控制字符整类处理，不只换行与制表符**。正文里 `%c` 一律转成 `\n`/`\r`/`\t`/`\xNN`；标识符（频道名、输出端名）里 `%c` 直接抛错。理由不是洁癖：一个 `\0` 让 grep 把整份日志判成二进制并停止打印匹配行，一个 `\027` 让日志查看器执行日志内容里的转义序列。
7. **上限不能被关掉**。四项都必须有限，`maxDepth` 另有上界（`MAX_DEPTH_LIMIT`）。能设成 `math.huge` 的深度上限等于拆掉唯一的递归保护，而「日志组件把宿主栈撑爆」是不可恢复的失败：它连测试报告都留不下。
8. **过滤只改投递，不改 API 形状**（W4）。被挡掉的记录照样构造、照样返回，调用方永远拿到一条记录 —— 否则「改一行日志配置」就变成一次全工程搜索替换。热路径真想省这次分配，用 `Neon.Enabled(level, channel?)` 守卫，它只读门槛、**不消费限速与折叠的账**。
9. **计数不新造记录、也不改冻结记录**（W4）。`repeated` / `rateDropped` 随同频道**下一条真正投递的记录**带出去；那个频道若再没有下一条，数就在 `Filter.Stats()` 里（W7 的控制台读它）。折叠优先于限速：一条记录不会被记两次账。每频道状态最多跟踪 256 个频道，超出的退回只走全局门槛并在账目里报出来 —— 「内存吃紧就把日志丢掉」是反过来的做法。
10. **命令层「运行不抛、注册必抛」**（W5）。`Run` 把畸形输入（引号不闭合、缺参数、类型不符、`nan`/`inf`）、未知命令、越权、handler 自己炸全部转成一行错误文本：控制台是人现场改东西的地方，一条打错的命令把调用栈甩在他脸上，他就再也看不清自己敲了什么。反过来，`kind` 写错、必填排在可选之后、`handler` 不是函数、命令名撞车都在 `Register` 当场抛 —— 留到运行期的症状是「那条命令偶尔不行」，而没人会去怀疑注册。权限钩子**抛错按拒绝处理**（安全检查起不来就当通过，是反过来的默认值）。`ArgSpec.kind` 的类型是 `string`（合法集合由注册期挡），理由写在 `Command.luau` 里。
11. **错误文本按尾巴截断**（W5）。`error()` 的返回值带 `路径:行号: ` 前缀，按头截断（`Level.Describe` 的做法）截出来的全是路径、原因正好被切掉 —— W5 的自检第一次跑 CI 就是这么挂的。`Command` 里的 `errorText` 因此是：控制字符整类换空格、上限 240 字节、**从尾部留**、掐掉被切坏的 UTF-8 续接字节。
12. **命令注册表不归 `Neon.Reset()` 管**（W5）。复位日志状态顺手把服务器上的命令一起端走，症状会出现在毫不相干的调用点上；要清自己的账用 `Command.Reset()`（它复位后内置 `help` 仍在 —— `help` 是注册进表里的，不是另写一份硬编码清单，这条也钉了用例）。
